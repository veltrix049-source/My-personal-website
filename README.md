# My-personal-website
My room

hii, welcome to my personal website. instead of a boring page, the homepage is my room (atleast what i  imagined). click the objects to find out more about me.

the computer opens "about me", the bookshelf shows my projects, and the mail is how you can contact me. there are also buttons under the room if you'd rather use those.

this is my first ever website. i learned most of it from youtube and trial and error, so some pixels are slightly crooked. i built it with just html and css, no javascript.
to run it, download the files and open index.html in your browser.
